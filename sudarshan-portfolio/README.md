## 🏆 What Makes This Portfolio Award-Winning?

1. **60 FPS Interactive Cyber Particle Canvas**:
   - Mouse-reactive dynamic particle constellation mesh background.
2. **Interactive Developer CLI Terminal (`Ctrl + ~` or header icon)**:
   - Run commands directly: `help`, `projects`, `pitch`, `skills`, `awards`, `eval`, `sudo hire`, `clear`.
3. **Live Project Simulators in Modals**:
   - **Annadata Kisan**: Test soil samples (Black, Alluvial, Red, Clay) with live simulated N-P-K nutrient bar calculations and AI crop recommendations.
   - **SAFE AI**: Interactive 24/7 mental wellness chatbot with prompt chips and real-time streaming responses.
   - **MedScan**: Adjust claim amounts and hospital risk ratings to calculate real-time fraud risk scores (0–100%) and fraud alert tags.
4. **Fullscreen Industry Presentation Slide Deck Mode**:
   - 6-Slide presentation deck with keyboard navigation (`←` / `→` / `Space` / `Esc`), live presentation timer, and clean presentation layout.
5. **Confetti Celebration & 3D Card Tilt Physics**:
   - Interactive 3D mouse tracking tilt on project and trophy cards with celebratory confetti explosions.
6. **Web Audio API Sound Effects**:
   - High-tech interactive audio clicks and hover tones synthesized dynamically in-browser (toggleable anytime).
7. **2-Minute Executive Recruiter Scan Mode**:
   - High-density comparative scorecard for fast judge evaluation and grading.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + ~` / `F2` | Toggle Developer CLI Terminal |
| `→` / `Space` | Next Slide (In Presentation Mode) |
| `←` | Previous Slide (In Presentation Mode) |
| `Escape` | Close Slide Deck / Modals / Terminal |

## ⚡ How to Run Locally

### Option 1: Python HTTP Server
```bash
python3 -m http.server 3000
```
Open `http://localhost:3000` in your web browser.

### Option 2: Node Serve
```bash
npx serve .
```

### Option C: GitHub Pages
1. Push to your GitHub:
   ```bash

   git add .
   ```
