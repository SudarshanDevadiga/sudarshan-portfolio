## 🌟 Overview

This is the official portfolio web application built for the **Student Portfolio Hackathon 2026** and placement / internship readiness. Designed as an interactive tech showcase featuring live sandboxes, an in-browser developer CLI terminal, full-screen presentation slide deck mode, and 60 FPS canvas particle physics.

---

## ✨ Key Interactive Features

- **🌌 60 FPS Cyber Particle Canvas**: Physics-driven interconnected constellation background reacting to mouse proximity.
- **💻 Built-in Developer CLI Terminal (`Ctrl + ~` / `F2`)**: Interactive command line interface (`projects`, `pitch`, `skills`, `awards`, `eval`, `sudo hire`, `clear`).
- **🧪 Live Project Simulators in Deep-Dive Modals**:
  - **Annadata Kisan**: Real-time soil image diagnostic sandbox with N-P-K nutrient bar calculations and AI crop recommendations.
  - **SAFE AI**: Interactive 24/7 mental wellness conversational AI agent with real-time streaming responses.
  - **MedScan**: Interactive medical insurance fraud risk radar (0–100%) with anomaly factor calculation.
- **📊 Fullscreen Industry Presentation Slide Deck**: 6-slide deck engineered for the compulsory hackathon evaluation with keyboard navigation (`←` `→` `Space` `Esc`) and live presentation stopwatch timer.
- **🏆 Hackathon Trophy Room**: Interactive 3D tilt cards with celebratory confetti explosions on award clicks.
- **🔊 Web Audio API Sound Synthesizer**: Zero-dependency procedural audio clicks and hover tones.
- **⚡ 2-Minute Executive Recruiter Scan Mode**: High-density scorecard table for fast evaluator grading.
